# 開発ブリーフ：作り方から選ぶこづゆ体験

更新日: 2026-11-01

## 何を、誰のために、なぜ作るか

こづゆに詳しくない人が、点数で正解を判定されるのではなく、「どんな作り方をしたいか」から材料と手順を選び、自分の選択に納得してこづゆを作れる体験へ変更する。

## 成功条件・受け入れ条件

1. 最初の画面で「お手軽に作る」「本格的に作る」「自分流に作る」から方針を選べる。
2. 材料画面では、選んだ方針に合う基本材料が理由付きでおすすめされ、初期選択される。
3. ユーザーは基本材料を自由に増減でき、写真読み取りの結果も同じ選択へ反映できる。
4. 「もっとおいしくするには？」に、干し貝柱や干し椎茸などの任意提案と、追加する意味が表示される。
5. 「完成！あなたのこづゆ」では、選択した方針・材料による特徴と分量を確認できる。
6. 調理手順は完成内容と別画面に分け、一つずつ進めたり前の手順へ戻ったりできる。
7. 点数、配点、再現度、点数に応じた評価コメントは、UI・データ・ロジックから削除する。
8. 最後の画面で、会津で受け継がれてきたこづゆの魅力と、現地で本場を味わう楽しさにつなげる。
9. スマートフォン幅を主対象とし、キーボード操作、押下状態、見出し構造を維持する。
10. テスト、lint、format check、production build が成功する。

## 対象ユーザーと主要ユースケース

- こづゆを知っているが、自分で作った経験が少ない人
- 会津の食文化に興味があり、まず身近な材料で試したい人
- 本格的な材料や手間を選ぶ理由を理解して作りたい人

代表フロー:

1. 作り方の方針を選ぶ
2. おすすめを起点に材料を調整し、任意のひと手間を選ぶ
3. 自分のこづゆの特徴と材料・分量を確認する
4. 独立した調理画面で手順を一つずつ進める
5. 会津の本場のこづゆへ関心を広げる

## MVP

### 含む

- 3つの作り方方針
- 方針別の基本材料の初期選択
- 写真読み取りと手動選択
- 理由付きの追加提案
- 選択内容に応じた既存レシピテンプレートの選択
- 特徴・材料・分量の確認画面
- 一つずつ進められる独立した調理手順画面
- 会津への導線
- 点数機能の完全撤去

### 含まない

- 新しい外部API、ログイン、保存、決済
- 店舗情報の新規調査や、確認できていない店名の表示
- AIによるレシピ生成
- ユーザーごとの履歴保存

### 将来候補

- 実地の試作結果に基づく方針別レシピの精緻化
- 了承済みの飲食店・販売店への具体的な導線
- 選択したレシピの共有

## 技術・設計

- 既存の TypeScript + React + Vite + Tailwind CSS を維持する。
- ルーターは追加せず、`App.tsx` の state で画面を切り替える。番号付きの体験は4ステップのまま、STEP 3だけを「完成内容」と「調理手順」の2画面に分ける。
- 作り方方針は型付きの静的定義とし、基本材料、説明、調理上の特徴を一か所で管理する。
- `buildResult` は材料からレシピ・代替行・会津で買う候補を組み立てる責務に限定し、点数計算を持たない。
- 画面に出す食文化・材料・分量の事実は、引き続き `kozuyu.json` を根拠にする。
- 写真判定は `pantry` の既知IDだけを追加し、失敗時は手動選択を継続できる。

## 主要画面とUI方針

1. **作り方を選ぶ**: 3枚の選択カード。各方針の優先事項と違いを短く明示する。
2. **材料を選ぶ**: 方針別おすすめの説明、写真読み取り、選択可能な材料一覧、理由付きの追加提案を同じ画面に置く。
3. **完成！あなたのこづゆ**: 方針と材料から生まれる特徴、選択材料、分量をまとめ、作る前の全体像を確認する。
4. **調理手順（STEP 3内）**: 追加材料の下処理を参照しながら、基本手順を一つずつ大きく表示する。「できた、次へ」「前の手順に戻る」で進め、最後は「できあがった！」でSTEP 4へ進む。
5. **本場のこづゆも食べてみよう**: 食文化の紹介、今回の選択とのつながり、確認済み範囲の会津の材料情報を表示する。

評価語は「正解／不正解」「本物に近い／遠い」ではなく、「この選び方で生まれる特徴」「追加すると得られる味や手間」を使う。

## テスト・品質基準

- 方針別の初期材料と説明を単体テストする。
- `buildResult` が材料の優先順位どおりにテンプレートと代替を選び、点数を返さないことを確認する。
- `kozuyu.json` 内の参照ID、列挙値、豆知識の必須項目を検証する。
- 主要画面をスマートフォン幅とデスクトップ幅で目視確認する。
- `prefers-reduced-motion` に依存する必須操作を作らない。

## リスク・仮定・未決事項

- 現在の分量と短時間手順には試作前の仮値が含まれるため、画面上の注記は残す。
- 「自分流」は初期材料を押し付けず、定番材料を参考表示して自由選択を優先する。
- 現地店舗への具体的リンクは確認済みデータがないため、今回のMVPでは食文化と会津産材料への関心喚起を中心にする。
