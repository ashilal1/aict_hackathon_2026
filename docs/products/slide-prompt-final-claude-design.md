# 成果発表スライド（修正版）：Claude Design 用プロンプト

作成: 2026-10-29

11/8 の成果発表スライド（16 枚版）へのレビューを反映して、Claude Design で作り直すためのプロンプト。
主な修正点:

- 田季野さんのヒアリング（10/26）の 1 枚を足し、年表・これからを更新
- 「確かめたデータ」と「仮の値」の食い違いをなくす
- 2 枚目（福島県在住のデータ）から 3 枚目（会津を離れた人の仮説）へのつなぎを足す。誰の課題かを明記
- こづゆが特別な日の料理であること（田季野さん「赤飯のような存在」）を入れる
- アプリの流れを #16 の画面（手軽さ選び・調理ガイド・完成）に合わせる
- 「22 の資料」の言い方、9 枚目の買い方、10 枚目の費用、写真の扱いの書き方を直す
- 本編では kozuyu.json・API・モデル名を出さず「データ」「AI」と書く（付録だけ残す）

画面写真とばあちゃんの画像は Claude Design では作れないので、プレースホルダーにしてあとで差し替える。

既存の 16 枚版を Claude Design 上で直す場合は、下の「修正プロンプト」を使う。一から作り直す場合は「プロンプト本文」を使う。

## プロンプト本文

```
AiCT ハッカソン 2026「会津の"おいしい"を、もっとおもしろくする。」の成果発表（2026/11/8 AiCT じものまつり）で使うスライドを作ってください。

# 発表の場面
- 大学生チーム「チーム D ソンご飯（孫ご飯）」の成果発表。作ったアプリ「こづゆばあちゃんの台所」を見せる
- 聞き手: 地域の団体・会津大学の関係者・会津の地元の人・他チームの学生。技術の細かい話より「誰の何を解決して、会津に何が返るか」を知りたい人たち
- 1 枚に伝えることは 1 つ。本文は短い言葉にし、文章で埋めない

# スライドの形式
- 16:9、日本語。本編 14 枚＋付録 3 枚
- 文字は会場の後ろからでも読める大きさにする
- 単語の途中で改行しない（「オイスターソース」「代わりがきかない」などが 2 行に割れないよう、枠の幅を取る）

# デザイン
- 色:
  - 漆黒 #1C1714: 表紙・デモ・締めの暗い背景、見出しの文字
  - 白壁 #F7F3EA: 本文スライドの背景
  - 朱 #B8312F: 強調。1 枚につき 1 か所まで
  - 藍 #2E3A5C: 小見出しのラベル、グラフ、サブの色
  - 金 #B8963E: 細い線、番号、小さなラベルだけ
- スライド下端に、会津木綿の縞（藍・朱・白壁の細いストライプ）の帯
- 各スライド左上に、小さな藍色のラベル（「課題」「つくったもの」など）
- 書体は見出しも本文もゴシック。丸文字・洋風レトロ書体は使わない
- ばあちゃんの画像は後で差し替えるので、丸い枠（外側に朱の太い縁、内側に細い金の線、中は白壁色）のプレースホルダーに「こづゆばあちゃん」と書いておく。絵は描かない
- アプリの画面写真も後で差し替えるので、角丸の黒い縁のスマホ枠に「画面写真（差し替え）：〇〇」と書いたプレースホルダーにする
- ばあちゃんのセリフは、丸い枠の下に白い吹き出しで出す
- 絵文字、意味のないグラデーション、飾りだけのアイコンは使わない

# 守ってほしいこと
- 下に書いた内容以外の事実・数字・出典を足さない
- 点数・分量はすべて「仮の値」。「確かめた」「正しい」「再現度」とは書かない
- 「仮説」と書いてあるスライドには、右上に金の枠の小さな「仮説」ラベルを付ける
```
